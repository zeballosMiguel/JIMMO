# JIMMO — Contexto del proyecto

## Negocio
JIMMO gestiona ventas de productos como ropa, mochilas y accesorios.
El negocio actualmente utiliza una hoja de cálculo con información de ventas, variantes, precios, vendedores, canales, entregas, pagos y utilidad.

## Realidad importante
- El mismo artículo puede venderse a diferentes precios.
- Hay diferentes vendedores.
- Existen múltiples canales de venta.
- Las entregas pueden ser retiro, feria, envío o delivery.
- El stock debe poder trazarse por variante y lote.
- El costo real de venta depende de FIFO.
- Existen clientes y deben formar parte del pedido.

## Ejemplos del negocio
La hoja histórica contiene productos como:
- Chamarra mujer 25-1485
- Chaleco calefactor 142493
- mochilas j25-04, j25-05, j25-12
- otros productos identificados por SKU/modelo.

Hay ventas del mismo producto a precios diferentes; por ello el precio no puede ser una propiedad única e inmutable del producto.

## Canales observados
TikTok, Facebook, Facebook ADS, Marketplace, Tienda, Puesto y otros.

## Vendedores observados
Saul, Carmen y otros usuarios que puedan existir en la operación real.

## Fuente histórica
La hoja de cálculo/PDF original es referencia del negocio real. No debe reinterpretarse como un esquema técnico superior a V4.1; se usa para comprobar que el sistema cubre las operaciones existentes.
